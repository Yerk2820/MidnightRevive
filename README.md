# MidnightRevive

MidnightRevive is a customizable Minecraft plugin that keeps players dead until midnight.

Upon death, players enter a spectator-like state at world spawn, where they must wait until the next revival.

## Features
- Midnight Revival
- Spectator Limbo
- Configurable Settings
- Dead Player Restrictions
- Optional Event Mode

## Installation
1. Download the plugin `.jar` file.
2. Place it in your server's `plugins` folder.
3. Restart your server.
4. Configure the plugin in `plugins/MidnightRevive/config.yml`.
